# Бот записи — простой способ (без терминала)

Всё делается в браузере: Google Таблицы + встроенный редактор кода Apps Script.
Ничего устанавливать не нужно. Таблица сама становится списком заявок — простой
админкой, а Telegram присылает уведомление с кнопками «Подтвердить/Отменить».

## Шаги

1. **Токен бота.** Написать [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` →
   получить токен вида `123456789:ABC-DEF...`.

2. **Создать Google Таблицу.** [sheets.google.com](https://sheets.google.com) → пустая таблица,
   можно назвать «Заявки Варг».

3. **Открыть редактор кода.** В таблице: меню **Расширения → Apps Script**.

4. **Вставить код.** Открыть файл `Code.gs` из этой папки, скопировать всё содержимое,
   вставить в редактор Apps Script (заменить то, что там было по умолчанию).

5. **Заполнить три строки в начале кода:**
   ```js
   const BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER";
   const ADMIN_CHAT_IDS = "СЮДА_ВАШ_CHAT_ID";
   const BOOKING_SECRET = "придумайте-случайную-строку";
   ```
   `ADMIN_CHAT_IDS` пока оставьте как есть — узнаем на шаге 8.

6. **Развернуть как веб-приложение.** Кнопка **Deploy → New deployment** (или «Развернуть →
   Новое развёртывание») → тип **Web app** → Execute as: **Me**, Who has access: **Anyone** →
   **Deploy**. Google попросит разрешить доступ скрипту — подтвердите (это ваш собственный скрипт).
   Скопируйте появившийся **Web app URL** — он понадобится дальше.

7. **Подключить вебхук Telegram.** Просто откройте в браузере (замените `<TOKEN>` и `<URL>`):
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=<URL>
   ```
   Должен появиться ответ `{"ok":true,...}`.

8. **Узнать свой chat_id.** Напишите вашему боту `/start` в Telegram — он ответит вашим chat_id
   (пока `ADMIN_CHAT_IDS` пуст). Вернитесь в редактор кода, впишите этот id в `ADMIN_CHAT_IDS`,
   нажмите **Сохранить** (значок дискеты) и переразверните: **Deploy → Manage deployments →
   значок редактирования → New version → Deploy**. Теперь вы админ, напишите `/start` ещё раз —
   бот покажет список команд.

9. **Подключить сайт.** В корневом `config.js` → `integrations.bookingEndpoint` укажите:
   ```
   <Web app URL>?key=<BOOKING_SECRET>
   ```

Готово. Сделайте тестовую запись на сайте — придёт сообщение с кнопками, а строка появится
в листе «Заявки» той же таблицы.

## Команды бота

- `/today` — заявки на сегодня
- `/upcoming` — ближайшие заявки (следующие 20)
- Кнопки под уведомлением — подтвердить или отменить конкретную заявку

## Если поменяли услуги или мастеров на сайте

Бот сам подставляет названия из заявки (они уже приходят с сайта в её теле), отдельно
синхронизировать список не нужно — в отличие от варианта на Cloudflare.

## Продажа шаблона другим барбершопам

Клиенту нужно повторить шаги 1–9 с его собственным ботом, таблицей и токеном — 10 минут,
всё в браузере. Права администратора — это просто chat_id в `ADMIN_CHAT_IDS`; можно
перечислить несколько через запятую, если у клиента несколько администраторов.

## Ограничения этого способа

- Бесплатный лимит Google Apps Script: 20 000 вызовов веб-приложения в день — для одного
  барбершопа более чем достаточно.
- Данные (имя, телефон) хранятся в Google Таблице — зарубежный сервис; те же оговорки
  по 152-ФЗ, что и в `TEMPLATE.md` и `bot/README.md` в корне.
- Если понадобится больше контроля или несколько барбершопов под одной инфраструктурой —
  в папке `bot/src` есть более продвинутый вариант на Cloudflare Workers.
