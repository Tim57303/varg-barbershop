# Бот записи — через Vercel (GitHub, без страшных предупреждений)

Как apps-script/ и src/ — тот же результат (уведомление в Telegram с кнопками
«Подтвердить/Отменить»), но разворачивается через **Vercel**: вход по GitHub, без
терминала и без предупреждений «Google не проверил это приложение». Без базы данных —
история заявок остаётся прямо в переписке с ботом в Telegram (это и есть архив).

## Шаги

1. **Токен бота.** У @BotFather в Telegram → `/newbot` → получить токен (если уже есть — пропустите).

2. **Зайти на [vercel.com](https://vercel.com)** → **Sign Up** → **Continue with GitHub** →
   разрешить доступ (стандартный, «чистый» экран авторизации GitHub, без предупреждений).

3. **New Project** → выбрать репозиторий `varg-barbershop` (Import).

4. **Важно:** в настройках перед деплоем раскрыть **Root Directory** и указать `bot/vercel`
   (это говорит Vercel развернуть только папку бота, а не весь сайт).

5. **Environment Variables** — там же на экране настройки, добавить три переменные:
   | Name | Value |
   | --- | --- |
   | `BOT_TOKEN` | токен из BotFather |
   | `ADMIN_CHAT_IDS` | пока оставить пустым — впишем на шаге 8 |
   | `BOOKING_SECRET` | любая случайная строка, например `varg2026secret` |

6. **Deploy.** Через минуту получите адрес вида `https://varg-barber-bot.vercel.app`.

7. **Подключить вебхук.** Открыть в браузере (заменить `<TOKEN>` и `<URL>`):
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=<URL>/api/telegram
   ```
   Ответ должен быть `{"ok":true,...}`.

8. **Узнать chat_id.** Написать боту `/start` — он ответит вашим chat_id (пока
   `ADMIN_CHAT_IDS` пуст). Зайти в Vercel → проект → **Settings → Environment Variables** →
   отредактировать `ADMIN_CHAT_IDS`, вставить этот id → **Save** → **Deployments** →
   на последнем деплое **⋯ → Redeploy**. Теперь вы админ.

9. **Подключить сайт.** В корневом `config.js` → `integrations.bookingEndpoint`:
   ```
   https://varg-barber-bot.vercel.app/api/booking?key=<BOOKING_SECRET>
   ```

Готово. Тестовая запись на сайте → сообщение в Telegram с кнопками. Вся история заявок —
просто сообщения в этом чате, прокрутите вверх, если нужно посмотреть старые.

## Продажа шаблона другим барбершопам

Тот же репозиторий, свой бот у BotFather, свой проект в Vercel (Import того же GitHub-репо
под аккаунтом клиента или вашим — кто хостит, тот и платит, но тариф бесплатный). Права
администратора — chat_id в `ADMIN_CHAT_IDS`, через запятую, если админов несколько.

## Ограничения

- Без базы данных нет команд `/today`/`/upcoming` — история заявок просматривается как
  обычная переписка в Telegram.
- Если у заявки несколько админов и двое одновременно нажмут кнопку — обработается
  последнее нажатие, это не страшно для одного барбершопа, но не абсолютная защита от гонки.
- Персональные данные (имя, телефон) идут через Vercel и Telegram — зарубежные сервисы,
  та же оговорка по 152-ФЗ, что в `TEMPLATE.md`.
