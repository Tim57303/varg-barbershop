# Шаблон: сайт барбершопа под нового клиента

Сайт собирается из одного файла настроек `config.js`. Под нового салона меняются настройки, фотографии и несколько строк в `index.html`. Ничего пересобирать не нужно: файлы открываются в браузере как есть.

## Что где лежит

| Файл | Зачем | Трогать под клиента |
| --- | --- | --- |
| `config.js` | название, контакты, услуги, цены, мастера, тексты, цвета, интеграции | **да, это главный файл** |
| `img/` | фотографии (`haircut.jpg`, `fade.jpg`…) | да, заменить на фото клиента |
| `index.html` | каркас страницы, `title`, `description`, адрес сайта в `<head>` | 6 строк в `<head>` |
| `privacy.html` | политика конфиденциальности (берёт реквизиты из `config.js`) | нет, только `legal` в настройках |
| `404.html` | страница «не найдено» | одна строка `<base href>` |
| `sitemap.xml`, `robots.txt` | для поисковиков | заменить адрес сайта |
| `og.jpg`, `favicon.svg` | картинка для ссылок в соцсетях и иконка | заменить на свои |
| `styles.css`, `app.js`, `fonts/` | вид и поведение | нет |
| `case/` | страница-кейс для портфолио | только для вас, клиенту не отдаём |

## Сборка сайта для клиента: чек-лист (≈ 1–2 часа)

1. **Скопируйте папку проекта** под именем клиента.
2. **Бренд** в `config.js`: `brand` (название, город, текст на печати), `theme` (цвета из фирменного стиля клиента).
3. **Контакты и адрес**: `contacts` (телефон, почта, адрес, метро, часы работы, соцсети). Пустая ссылка в `social` не показывается.
4. **Услуги и цены**: `prices.services`. Для каждой услуги: `id` (латиницей, уникальный), название `n`, минуты `m`, цена `p`. Группы `g` любые.
5. **Пояснения терминов**: `gloss`. Ключ = `id` услуги. Если пояснение не нужно, удалите запись: значок «?» пропадёт.
6. **Мастера**: `masters.list`. Теги `tags` — пары `[id услуги, подпись]`. Поле `to` — имя в дательном падеже для кнопки «Записаться к …».
7. **Главный экран и экран «Услуги»**: `hero`, `stage.items` (3–5 услуг с фото и описанием). Высота экрана подстраивается под число позиций.
8. **Фото**: положите свои в `img/` (JPEG, по длинной стороне до 1600 px, до 250 КБ каждое) и укажите имена в `config.js`. Для интерьера и «работ» нужны цветные снимки. Если фото чёрно-белое, поставьте `mono: true`.
9. **Карта**: `map.mode: "yandex"` и адрес виджета из конструктора карт Яндекса. Нарисованная схема в демо подходит только для демонстрации.
10. **Реквизиты**: `legal` (ИП/ООО, ИНН, ОГРН, адрес, почта, дата редакции). Они появятся в подвале и в политике конфиденциальности.
11. **`<head>` в `index.html`**: `title`, `description`, `canonical`, `og:title`, `og:description`, `og:url`, `og:image`. Те же адрес и название в `config.js` → `seo.url`.
12. **`sitemap.xml` и `robots.txt`**: замените адрес сайта. В `404.html` замените адрес в `<base href>`.
13. **Иконка и превью**: замените `favicon.svg` и `og.jpg` (1200×630).
14. **Проверьте на телефоне и компьютере**: прокрутка услуг, форма записи, подсказки «?», политика, 404.

## Запись и оплата

По умолчанию форма работает в демо-режиме: заявка остаётся только в браузере посетителя, а на талоне видна пометка. Чтобы принимать настоящие заявки, выберите один из вариантов.

| Вариант | Как | Плюсы и минусы |
| --- | --- | --- |
| **Виджет YClients / Dikidi / Altegio** | вставить их код записи вместо блока `#zapis` | готовый календарь, напоминания, оплата; платно у клиента |
| **`bookingEndpoint`** | адрес, куда сайт шлёт заявку методом POST (JSON) | просто; занятое время между посетителями не синхронизируется |
| **Свой сервер** (Яндекс Облако, Timeweb, Supabase) | таблица слотов + приём заявок + уведомление в Telegram | полный контроль и общий календарь; нужна разработка |

Формат заявки, которую отправляет сайт:

```json
{ "no": "4821", "date": "2026-09-23", "hour": 15, "master": "artem", "service": "combo",
  "name": "Иван", "phone": "+7 (999) 123-45-67", "price": 4200,
  "pay": { "method": "prepay", "amount": 1260, "status": "pending" }, "status": "new" }
```

**Оплата.** В `integrations.paymentUrl` вставьте шаблон ссылки платёжного сервиса (ЮKassa, Т-Банк, ЮMoney, CloudPayments, СБП): `https://…?sum={amount}&order={order}&comment={desc}`. Кнопка «Перейти к оплате» подставит сумму, номер записи и описание. Автоматически подтвердить оплату (вебхук) может только серверная часть.

## Юридическое: обязательно проговорите с клиентом

- Форма собирает **персональные данные** (имя, телефон). Нужны согласие (галочка в форме уже есть) и политика конфиденциальности. Шаблон в `privacy.html` типовой: **его должен проверить юрист**, реквизиты подставляются из `legal`.
- По **152-ФЗ (локализация)** персональные данные граждан РФ при сборе должны сначала записываться в базы на территории России. Если заявки хранятся в зарубежном сервисе (например, Google Таблицы), это риск. Безопаснее российские сервисы записи или хранилище в России.
- Если подключаете **Яндекс Метрику**, укажите счётчик в `integrations.yandexMetrika`. Политика уже упоминает веб-аналитику.
- Стоковые фото (Unsplash) разрешено использовать бесплатно, но для клиента лучше свои снимки.

## Публикация

- **GitHub Pages** (бесплатно): загрузите папку в репозиторий, в Settings → Pages выберите ветку `main` и `/ (root)`.
- **Netlify / Cloudflare Pages** (бесплатно): перетащите папку в окно сервиса.
- **Российский хостинг**: загрузите файлы в корень сайта.
- **Домен**: `.ru` покупается у регистратора, подключается записями DNS у сервиса публикации.

## Передача клиенту

Отдайте клиенту:

1. Адрес сайта и доступ к хостингу и домену (лучше оформить на клиента).
2. Папку проекта целиком.
3. Короткую инструкцию: «Чтобы поменять цену, откройте `config.js`, найдите услугу и измените `p`». Все правки: тексты, цены, мастера, часы, ссылки — только в `config.js`.
4. Список того, что подключено (запись, оплата, аналитика), и кто за что отвечает.

## Как показать в портфолио

Страница `case/index.html` показывает сайт живьём в рамках компьютера и телефона, рассказывает задачу, решения и границы демо. Перед публикацией впишите свои контакты в `SELLER` в конце файла, и появится кнопка «Написать».
