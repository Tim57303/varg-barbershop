# ВАРГ — барбершоп у метро «Студенческая»

Одностраничный сайт барбершопа: услуги с пояснениями терминов, прайс, мастера, работы, онлайн-запись с выбором оплаты, схема проезда.
Чистый HTML/CSS/JS, без сборки и зависимостей — сайт лежит в одном файле `index.html`, фото в папке `img/`.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на github.com (например, `varg-barbershop`) и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Что заменить перед запуском

Всё в `index.html`. Ищите по тексту:

| Что | Где искать |
| --- | --- |
| Название «ВАРГ» | `<title>`, логотип, заголовки, футер |
| Адрес, часы работы, телефон | блоки «Как найти», футер, `tel:+74950000000` |
| Услуги и цены | массив `SERVICES` в начале скрипта |
| Пояснения терминов | объект `GLOSS` |
| Мастера | секция `id="mastera"` |
| Фото | папка `img/` (сейчас стоковые фото Unsplash) |

## Запись и оплата

Сайт статический, базы данных на GitHub Pages нет. Форма записи работает так:

- **`BOOKING_ENDPOINT`** (начало скрипта) — адрес, куда уходит заявка методом POST в формате JSON:
  Telegram-бот через прокси-функцию, CRM, Google Apps Script, Formspree и т. п. Пока пусто, заявка остаётся только в браузере посетителя.
- **`PAYMENT_URL`** (начало скрипта) — шаблон ссылки на оплату в вашем платёжном сервисе (ЮKassa, ЮMoney, Т-Банк, CloudPayments, СБП), например
  `https://pay.example.ru/?sum={amount}&order={order}&comment={desc}`.
  Кнопка «Перейти к оплате» подставит сумму, номер записи и описание. Пока пусто, кнопка работает в демо-режиме.
- Общие занятые слоты между посетителями и журнал записей для администратора требуют серверной части (Supabase, Firebase, свой бэкенд).
  Не храните ключи и пароли в `index.html`: он публичный. Журнал должен открываться только после входа администратора на стороне сервера.

Для готовой записи с календарём, напоминаниями и оплатой можно подключить виджет YClients, Dikidi или Altegio вместо формы.

## Сборка одним файлом

`ruby build.rb` создаёт `dist/varg-single.html` — тот же сайт со встроенными фото, его можно открыть где угодно без папки `img/`.
