# ВАРГ — сайт барбершопа

Одностраничный сайт барбершопа у метро «Студенческая» в Москве. Чистые HTML, CSS и JavaScript, без фреймворков и сборки. Это демо-проект и одновременно **шаблон**: под нового клиента меняется один файл настроек.

- Сайт: <https://tim57303.github.io/varg-barbershop/>
- Кейс для портфолио: <https://tim57303.github.io/varg-barbershop/case/>
- Как собрать сайт под нового клиента: [TEMPLATE.md](TEMPLATE.md)

## Что внутри

| Файл или папка | Назначение |
| --- | --- |
| `index.html` | каркас страницы и мета-теги |
| `config.js` | **все настройки и тексты**: название, контакты, услуги, цены, мастера, фото, цвета, интеграции |
| `styles.css`, `app.js` | вид и поведение (менять не нужно) |
| `fonts/` | шрифты Oswald, Manrope, IBM Plex Mono (кириллица, лицензия OFL), хранятся на самом сайте |
| `img/` | фотографии |
| `privacy.html` | политика конфиденциальности по 152-ФЗ (реквизиты берёт из `config.js`) |
| `404.html`, `robots.txt`, `sitemap.xml`, `favicon.svg`, `og.jpg` | служебное для поисковиков и соцсетей |
| `case/` | страница-кейс с живым превью сайта |
| `build.rb` | сборка `dist/varg-single.html`: весь сайт в одном файле |

## Возможности

- Экран «Услуги»: фото на весь экран сужается косым срезом, кадры сменяются «проходом бритвы».
- Подсказки «?» с простыми пояснениями терминов (Fade, окантовка, под насадку…).
- Онлайн-запись в четыре шага: услуга и мастер, время, контакты и согласие на обработку данных, оплата.
- Оплата: в салоне, предоплата или полностью, переход в платёжный сервис по ссылке из `config.js`.
- SEO: мета-теги, Open Graph, микроразметка BarberShop (услуги, цены, часы), `sitemap.xml`.
- Адаптивная вёрстка, управление с клавиатуры, учёт `prefers-reduced-motion`.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
Подойдут и Netlify, Cloudflare Pages или любой хостинг статических файлов.

## Запись и оплата

Сайт статический. Без серверной части форма работает в демо-режиме (заявка остаётся в браузере посетителя). Как подключить приём заявок и оплату, описано в [TEMPLATE.md](TEMPLATE.md), разделы «Запись и оплата» и «Юридическое».
